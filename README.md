# Workbine

Workbine is a community-driven platform for discovering how people actually do things in practice.

Users create a topic or goal, for example `How to build a SaaS with Gemini`, and anyone can publish their own method or workflow under that topic. Other people can then validate, compare, improve, and discuss those methods based on real experience.

## V1 core

`Goal -> Method -> Experience -> Evidence`

The product should prioritize practical experience, freshness, and credibility over simple popularity.
